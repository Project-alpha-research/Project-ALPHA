# Documentation index

Where each kind of document lives, and how long it stays current. Tasks are routed by the root
[`CONTEXT.md`](../CONTEXT.md); documentation work starts at [`docs/CONTEXT.md`](CONTEXT.md). Rules live in
[`reference/invariants/`](reference/invariants/documentation.md) and the command list: `uv run python scripts/commands_reference.py`.

**What works today:** `uv run python scripts/status.py` (made on demand). **What the codes mean:** [glossary](reference/glossary.md).
**What production ready means, row by row:** the [production-ready scope](roadmap/production-scope.md) checklist.

## Lifecycle

| State | Meaning | Edited how | Where |
|---|---|---|---|
| Living | Describes the system or a procedure as it is now | Updated in place when behaviour changes | `ARCHITECTURE.md`, `reference/`, `governance/` (hand-written files), `operations/` |
| Decision | Records a choice and its reasons | Decision text is not rewritten; dated status notes and forward links are added when a newer record supersedes it | `adr/` |
| Intent | Wanted or staged work not yet built | Removed when the work lands; its pull request is the record | `roadmap/` |
| Record | True as of its date; kept for provenance | Left as-is; path-only link fix-ups allowed | `operations/retrospectives/` |
| History | What was done and why | Never edited: it is git log and the pull requests | git (older plans, records and archives: tag `pre-thin-2026-11-14`) |
| Generated | Produced by a tool; never hand-edited | Regenerated by its command (below) | parts of `governance/` |

## Folders

| Path | What belongs there |

| [`ARCHITECTURE.md`](ARCHITECTURE.md) | Current package boundaries, layered DAG and runtime components. |

## Generated files

Do not edit these by hand; rerun the command and commit the result.
The command list, the status page and the roadmap index are not stored: print them with
`uv run python scripts/commands_reference.py`, `scripts/status.py` and `scripts/roadmap_index.py`.

| Files | Command |
|---|---|
| `docs/governance/capability-authority-matrix.md`, `docs/governance/openapi-operation-classification.json` | `uv run python scripts/check_openapi_operations.py --write` (without `--write` it checks) |

To find a document, run `uv run python scripts/fs.py orient` or `fs.py search "<words>"`.

- Generated pages are never edited by hand; their commands are listed in
  [docs/README.md § Generated files](README.md#generated-files).

## Plan lifecycle

A wanted feature with no plan is one short file in [`roadmap/backlog/`](roadmap/backlog/); staged
structural refactors use [`roadmap/refactors/`](roadmap/refactors/). Turning either into delivered
work follows [the build team](reference/project/components/delivery-and-agent-tooling.md); the pull request is the
record.
