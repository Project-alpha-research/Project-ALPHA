# Workstation screen ideas from the owner's reference images

**Status:** Idea
**Rough size:** M

## Problem / why

The owner collected dashboard and results-page screenshots as design references. Most are covered by
built figures. These are not.

- Named market-event bands (crises, rate shocks) on the equity and drawdown charts, each toggled.
- A gallery of small diagnostic cards, each opening a plain explanation: what it means, a good range,
  how to improve.
- A model card: inputs ranked by importance, training window, signal definition, and a chart of
  confidence threshold against win rate that ends by asking for a backtest.
- A winners-versus-losers explorer showing what each looked like before entry, against random dates.
- A Coppock curve panel beside the other indicator panels.
- A correlation heatmap across any chosen assets, not only portfolio sleeves.
- Yearly returns as bars coloured over or under the benchmark.
- Signals and indicators exported to the owner's own charting platform for a human final call.
